# iPhone 快捷指令「存到拾藏」

iOS 版出来前，手机上的收藏入口。手机只负责「记下链接」，抓取、存图、分类都由 Mac 上的拾藏完成。

## 怎么用

- **X App / Safari / 大多数 App**：分享 → 「存到拾藏」→ 顶部弹通知「已存好」。
- **微信公众号**（微信不给系统分享面板）：文章右上角「…」→ 复制链接 → 回桌面点「存到拾藏」图标（或设成「轻点背面」）。没有分享输入时，快捷指令会自动读剪贴板。
- 手机离线也能存，联网后经 iCloud 同步到 Mac。

## 它做了什么

1. 拿到分享内容（链接或文字）；没有分享内容就读剪贴板。
2. 记下设备名和当前时间（ISO 8601）。
3. 拼成词典 `{share_text, device, captured_at, from}`。
4. 存为 `iCloud 云盘/快捷指令/拾藏Inbox/拾藏-<yyyyMMdd-HHmmss>.json`，不问存哪、不覆盖。
5. 弹通知。

Mac 上的拾藏监听这个文件夹（另有 60 秒兜底轮询），收进队列后删掉文件。收藏时间以手机上按下的时间为准，来源显示「快捷指令 · 设备名」。

需要 Mac 和 iPhone 登录同一个 Apple ID，并且都打开了 iCloud 云盘。

## 安装

仓库里不带现成的 `.shortcut` 文件（签过名的文件会带上签名者的 Apple ID 信息），自己生成一份，几秒钟的事。

**方法一：在 Mac 上生成并签名（推荐）**

```sh
/usr/bin/python3 scripts/make_shortcut.py shortcuts/存到拾藏-unsigned.shortcut
shortcuts sign --mode people-who-know-me --input shortcuts/存到拾藏-unsigned.shortcut --output shortcuts/存到拾藏.shortcut
```

- 用隔空投送把 `shortcuts/存到拾藏.shortcut` 发到 iPhone → 打开 → 「添加快捷指令」。
- 首次运行会问「允许访问快捷指令文件夹」「允许发送通知」，都点允许。

> 为什么用「认识我的人」模式：签名者就是你自己，导入自己的设备够用。「任何人」模式要经快捷指令的 iCloud 签名服务，Mac 上没开快捷指令 iCloud 同步时会报「必须登录 iCloud」。

**方法二：手动搭（导入不了时）**

在 iPhone「快捷指令」App 里新建，依次添加：

| # | 动作 | 设置 |
|---|------|------|
| 1 | 获取设备详细信息 | 设备名称 |
| 2 | 格式化日期 | 日期＝当前日期；格式＝ISO 8601；包括时间＝开 |
| 3 | 格式化日期 | 日期＝当前日期；格式＝自定义 `yyyyMMdd-HHmmss` |
| 4 | 词典 | `share_text`＝快捷指令输入；`device`＝设备详细信息；`captured_at`＝第 2 步的格式化日期 |
| 5 | 设定名称 | 词典 → `拾藏-`＋第 3 步的格式化日期＋`.json` |
| 6 | 存储文件 | 重新命名的项目；「询问存储位置」关；子路径 `拾藏Inbox/`；覆盖关 |
| 7 | 显示通知 | 「已存好」 |

快捷指令详情（ⓘ）：

- 打开「在共享表单中显示」，接收类型勾 URL、文本、富文本。
- 「无输入时」选「获取剪贴板」。

## Mac 端认什么

`Inbox.parseForeign` 字段名很宽松，别的工具（自己写的快捷指令、脚本）往这个文件夹放文件也能收：

- 文字：`share_text` / `shareText` / `text` / `input`
- 链接：`url` / `URL` / `link`
- 设备：`device` / `device_name`
- 时间：`captured_at` / `capturedAt` / `date`。ISO 8601 带不带小数秒都行；`yyyy-MM-dd HH:mm:ss` 按本地时区解析；也认 Unix 秒和毫秒。

扩展名认 `.json`、`.txt`、`.webloc`、`.url` 和无扩展名。`.json.json` 也能认（快捷指令「设定名称」有时会多补一个扩展名）。
